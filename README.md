# Robotics daily labs

77 small daily labs that cover every concept in the Skill Hub of the robotics prep sheet (232 concepts, including the
bus and compute selection maps) plus a ROS 2 track. Each lab is a Google Colab notebook:

| Part | What it is |
|---|---|
| Map | the concept as tables, diagrams and LaTeX math |
| Tasks | stubs you fill in, each followed by `lab.check(...)`, an automatic grader |
| Math checkpoint | numeric answers, `lab.answer(...)` |
| Concept checkpoint | one multiple choice, one written explanation scored against a rubric |
| Score | `lab.score()` prints one line: code, math, concept, hints, minutes, score out of 10 |

Bloom levels 1 to 5 are tagged on every checkpoint question.

## Daily routine

1. Open today's lab from [SCHEDULE.md](SCHEDULE.md) (Colab badge at the top of each notebook).
2. **File → Save a copy in Drive** (or GitHub) so your work survives the session.
3. Run the setup cell. It clones this repository into the Colab machine and loads the graders.
4. Cold attempt: notes closed, no AI, no internet. Fill every `TODO`, run the check under it.
5. Do both checkpoints, then `lab.score()`.

Scoring: code 4 points (checks passed / checks in the lab), math 3, concept 3 (choice right plus the rubric points you
honestly hit). `lab.hint("name")` is allowed but logged, because a hinted attempt is not a cold attempt.

## Languages

| Layer | Language | How the grader takes it |
|---|---|---|
| Bare metal (C01 to C08) | C | compiled with sanitizers, or run on an emulated Cortex-M3 (QEMU) |
| Drivers, protocols, control, real-time, reliability, hardware | Python **or** C/C++ | the C/C++ cell after each task includes `roboprep/c/include/<lab>.h`; `lab.check("name", "file.c")` compiles it into a shared library and runs the **same tests** |
| ROS 2 nodes | Python (rclpy) **or** C++ (rclcpp) | `lab.check("name", "node.cpp")` builds a colcon package around your file and runs the same checker against it |
| Vision, estimation, planning, learning, compute | Python | |

A check counts as passed if either language passes. C/C++ details:

- `gcc -std=gnu11` for `.c`, `g++ -std=gnu++17` when any file is `.cpp`, both with `-Wall -Wextra`; warnings are shown.
- C++ files implement the header's functions (they have C linkage) and can use classes and the standard library inside.
- Tests run in a forked process: a segfault or an infinite loop is reported as a failed check, not a dead notebook.

Python only, by nature: the BitBake evaluator and sstate tasks (R05, R06: BitBake itself is Python), the traceability
parser (RS02), quizzes, launch, URDF, YAML and device tree files, the QoS rules function (ROS03), and the behavior
tree composition (RS07 Task 2; the node classes in Task 1 have a C/C++ path).

First ROS lab of a Colab session: ROS 2 Jazzy installs through RoboStack in 3 to 5 minutes. The first C++ ROS check
adds compilers and takes 1 to 2 minutes per node build.

## Adding harder levels

Every notebook ends with a **Level 2 and beyond** section that says exactly where things go:

1. A markdown cell and a stub cell in the notebook, above the score cell.
2. A grader `check_L2_<name>` in `roboprep/checks/<lab>.py` (plus `c_L2_<name>(lib)` for a C/C++ path).
3. `lab.check("L2_<name>", ...)` under the stub. Every `check_` function counts toward the code score.
4. Commit to your branch and set `BRANCH` in the setup cell so Colab clones it.


## Solutions

The answer keys live in a separate private repository, `robotics-daily-labs-solutions`, so this one stays a clean slate
for you and for anyone who branches from it. To verify the graders against them, clone both side by side and run:

```bash
python tools/run_all.py --keys ../robotics-daily-labs-solutions/answer_key
```

The graders in `roboprep/checks/` hold expected values; do not open them before you score.

## Layout

```
labs/<track>/<ID>_<title>.ipynb   the labs (the source of truth: edit these directly)
roboprep/core.py                  Lab: checks, answers, rubric, score
roboprep/cbind.py                 C/C++ grading: compile, wrap with ctypes, run isolated
roboprep/ros.py                   ROS 2 environment, background nodes, colcon builds for C++ nodes
roboprep/checks/<lab>.py          one grader per lab
roboprep/c/include/<lab>.h        C/C++ declarations for each lab
curriculum/concepts.csv           the 232 concepts
curriculum/labs.csv               lab list for importing into the sheet
SCHEDULE.md, CURRICULUM.md        generated by tools/index.py from the notebooks' metadata
tools/run_all.py                  run notebooks headless (blank labs, or answer keys with --keys)
tools/index.py                    rebuild the schedule and coverage after adding or renaming a lab
```
